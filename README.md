# Atividade aplicação de desconto ADS 06
## Objetivo do projeto
O código tem como objetivo calcular descontos aplicados a uma compra, na qual os operadores relacionais foram usados para aplicar condições eespecíficas para descontos de 5%, 10% e 15%. O calculo é feito e depois as informações são apresentadas na saída com valor da compra, valor do desconto e total final com desconto aplicado.

## O que foi aplicado

    - if/elif/else
    - operadores relacionais 
    - float/input
